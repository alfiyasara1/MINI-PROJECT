# MINI-PROJECT
This project analyzes e-commerce sales data using Excel and Power BI. Excel was used for data cleaning, removing duplicates, handling missing values, and creating Pivot Tables. Power BI was used to create interactive charts, KPI cards, and slicers to analyze revenue by region, product category, payment method, and monthly sales trends.
# E-Commerce Sales Analysis

## Project Documentation

### 1. Introduction

This project focuses on analyzing e-commerce sales data using Microsoft Excel and Power BI to understand sales performance and revenue distribution.

### 2. Objectives

- To clean and prepare the sales dataset.
- To analyze revenue by region, product category, and payment method.
- To visualize monthly sales trends.
- To create an interactive Power BI report.

### 3. Tools Used

- Microsoft Excel
- Microsoft Power BI

### 4. Dataset Description

The dataset contains e-commerce order details, including order date, customer ID, product category, region, quantity, unit price, discount, payment method, delivery days, customer rating, and revenue.

### 5. Data Preprocessing

The dataset was cleaned in Excel by removing duplicate records, handling missing values, and checking data formats for consistency. Pivot Tables were created to summarize revenue by region, product category, and payment method.

### 6. Data Visualization

Power BI was used to create KPI cards, clustered column charts, a line chart, a donut chart, a pie chart, and a region slicer. These visuals help analyze total revenue, total orders, total quantity sold, regional revenue, category performance, payment methods, and monthly revenue trends.

### 7. Conclusion

This project demonstrates how Excel and Power BI can be used to clean, analyze, and visualize e-commerce sales data. The report provides a clear overview of sales performance and helps users understand revenue patterns across different categories.
